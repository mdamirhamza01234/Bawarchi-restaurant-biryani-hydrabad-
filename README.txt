BAWARCHI RESTAURANT WEBSITE — WEBSITE DEMO

Files:
- index.html: complete responsive website
- assets/: restaurant photos and menu photos supplied by the user

To preview:
1. Extract the ZIP.
2. Open index.html in a browser (or upload the folder to GitHub Pages / Netlify / Vercel).

Features:
- Responsive premium restaurant landing page
- Menu filters and add-to-order cart
- WhatsApp order enquiry demo
- Party/function enquiry form
- Restaurant gallery, contact details and Google Maps embed
- User-provided restaurant and menu photos

Important:
- Menu prices are transcribed from user-provided menu photos. Confirm current availability and rates with the restaurant.
- Website is a front-end demo. It does not send/confirm real restaurant orders or process payments.
- Sample review text is explicitly illustrative, not genuine customer testimonials.
- Illustrative food photos are loaded from Unsplash; an internet connection is needed for those images.
